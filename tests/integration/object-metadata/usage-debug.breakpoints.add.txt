debug.breakpoints.add <addr> [condition] [space: logical | physical]
  addr       uint, hex  Address to stop at
  condition  string     Expression; the breakpoint fires only when it is true
  space      enum       Address space (default logical)
Returns: the breakpoint entry
e.g.  debug.breakpoints.add 0x408986
      debug.breakpoints.add 0x408986 "d0 == 0" physical

Add a breakpoint; adding an address that already has one returns that
entry. space=physical stops on a physical address (through the 68030
PMMU)
