# Vectors the suite does not replay: known disagreements between this
# emulator's cores and the m68k-sail model (see INTEGRATING.md §"When your
# emulator disagrees" — each is a bug report for one side or the other,
# not a predecode question: both executors fail them identically).
#
#   <member> exception <name>   -- drop vectors whose outcome is that exception
#   <member> file <mnemonic>    -- drop the mnemonic's whole file
#   <member> prefix <text>      -- drop every mnemonic starting with the text
#
# filter.py prints what each rule dropped; a rule that drops nothing is
# flagged as stale.  Counts below are from the smoke tier at m68k-test
# 6dee945 (model bdf24ed).  The rules whose cause is suspected to be on the
# vector/model side are written up, with the report fields, in
# local/gs-docs/notes/2026-09-02-m68k-test-vector-disagreements.md; the rest
# are this emulator's own gaps.

# --- 68000 ---------------------------------------------------------------
68000 exception address-error -- the 68000 core completes odd-address word/long operand accesses instead of raising an address error (17 vectors)

# --- 68030 (68882) -------------------------------------------------------
68030 exception format-error -- FRESTORE accepts any frame: the version/size word is not validated
68030 prefix fb   -- FBcc on a NAN with a non-aware predicate: the model re-derives the whole AEXC byte from the (randomized, stale) EXC byte when it sets BSUN; the core accrues IOP only (the 2026-09-02 m68k-test note, item 4)
68030 prefix fdb  -- FDBcc: as FBcc
68030 prefix ftrap -- FTRAPcc: as FBcc
68030 file fnop   -- FNOP is FBF: as FBcc
68030 file fabs   -- unnormalized / denormalized extended operands are normalized differently
68030 file fadd   -- as fabs
68030 file fdiv   -- denormalized result representation (exponent 0 vs 1)
68030 file fgetman -- unnormalized operand handling
68030 file fmul   -- single-precision denormal operand treated as normalized
68030 file fscale -- scaling of an unnormalized operand
68030 file fsgldiv -- single-precision rounding of denormal operands
68030 file fsglmul -- as fsgldiv (FPSR accrued bits)
68030 file fatan  -- mantissa/sign of the result for one operand class
68030 file fcmp   -- packed-decimal source conversion
68030 file fintrz -- packed-decimal source conversion
68030 file fmovecr -- undefined ROM offsets: the core flags INEX, the model returns exact zero
68030 file fmove  -- reserved FPCR bits 3:0 / FPSR bits 31:28, 2:0 are writable in the model and masked in the core
68030 file fmovem -- register-list loads of unnormalized images, and the reserved-bit rule of fmove
68030 file link   -- LINK A7: the core pushes the pre-decrement SP, the model the post-decrement value; MAME agrees with the core on the 68000 (the 2026-09-02 m68k-test note, item 11)
68030 file chk    -- the CHK frame's stacked SR carries the model's values of the Z/V/C flags the vector itself marks undefined: a gap in the vector format to report upstream, not a core difference

# --- 68040 ---------------------------------------------------------------
68040 exception line-1111 -- the FP instructions the 68040 leaves to the FPSP (transcendentals, FMOVECR, FINT/FINTRZ, FSCALE, FMOD/FREM, FGETEXP/FGETMAN, FSINCOS) are computed in-line instead of taking the unimplemented-instruction exception
68040 exception fp-unimplemented-data-type -- packed-decimal operands are converted in-line instead of taking the unimplemented-data-type exception
68040 exception format-error -- FRESTORE accepts any frame
68040 prefix fb   -- FBcc: as on the 68030
68040 prefix fdb  -- FDBcc: as on the 68030
68040 prefix ftrap -- FTRAPcc: as on the 68030
68040 file fnop   -- as on the 68030
68040 file fsoge  -- FScc: as FBcc
68040 prefix fs   -- the 68040's single-rounded FSxxx opcodes are incompletely implemented (results not rounded to single, some forms not executed); also covers fsub/fsqrt/fsub whose vectors share the operand classes of fabs/fadd below
68040 prefix fd   -- the 68040's double-rounded FDxxx opcodes: as FSxxx
68040 file fabs   -- as on the 68030
68040 file fadd   -- as on the 68030
68040 file fcmp   -- packed-decimal source conversion
68040 file fmove  -- reserved FPCR/FPSR bits: as on the 68030
68040 file fmovem -- as on the 68030
68040 file bfffo  -- register-offset form: the core writes the full 32-bit offset plus position to Dn, the model (and MAME) the offset modulo 32
68040 file cas2   -- duplicated compare/update registers (Dc1 = Dc2, Du1 = Du2): update ordering
68040 file ptestr -- PTEST with translation disabled: the core reports R (resident) in MMUSR, the model leaves it clear
68040 file ptestw -- as ptestr
