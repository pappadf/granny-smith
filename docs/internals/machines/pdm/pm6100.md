# Power Macintosh 6100/60 (`pm6100`)

The first PowerPC Macintosh ("PDM"/"Piltdown Man", March 1994): 60 MHz
MPC601, 30 MHz bus (2:1), machine-ID register `$A55A3010`.  One SIMM-pair
socket: its two banks decode at `$10000000`/`$08000000` at power-on and
are relocated contiguously after the 8 MB soldered bank by the HMC
SIMM_BANK_SIZE config write (hmc.md); with bank 2 empty the code stays 0
and bank 1 answers at the motherboard top as well.  Single PDS slot, and the NuBus
adapter card that would carry the bridge is not modeled: the ROM's
`$F0000000` presence probe faults, `BARTExists` stays clear, and the
machine boots with no NuBus sockets at all (bart.md).  RAM options
8–72 MB (default 24 MB — the config that exercises the bank relocation).
