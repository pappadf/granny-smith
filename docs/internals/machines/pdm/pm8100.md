# Power Macintosh 8100/80 (`pm8100`)

The PDM flagship ("Cold Fusion", March 1994): 80 MHz MPC601, 40 MHz bus
(2:1), machine-ID register `$A55A3013`.  Eight fixed-window SIMM banks
(RAM options 8–264 MB); three NuBus slots (`$C`/`$D`/`$E`) behind BART,
plus the PDS video slot `$E`, for which no card is modeled; the second,
discrete 53CF96 fast-SCSI bus.  The Workgroup Server 9150 is this board
(wgs9150.md), so its shared board and profile fields are macros in `pdm.h`
(`PDM_8100_BOARD_COMMON`, `PDM_8100_PROFILE_COMMON`) and its SIMM totals
the exported `pm8100_ram_options_kb`.
