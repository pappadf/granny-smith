# Heathrow's ATA cells

The two IDE/ATA interface cells of Heathrow at `+$20000` and `+$21000` (`compatible "heathrow-ata"`), each a task file on 16-byte centres with an alternate-status register at `+$160`, a timing register at `+$200`, its own DBDMA channel and interrupt source.
