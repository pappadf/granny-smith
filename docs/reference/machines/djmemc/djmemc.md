# The djMEMC family — Centris 610/650, Quadra 610/650/800, LC 475/575, Quadra 605

> 🚧 **Placeholder** — this page is planned but not yet written.
<!-- gs-doc-status: stub -->

The 1993 68040 generation built around the djMEMC memory controller, the IOSB I/O controller, the Kiwi NuBus controller and the Antelope CLUT/DAC: the "Wombat" board (Centris 650, Quadra 650, Quadra 800; three NuBus slots) and the "WLCD" board (Centris 610, Quadra 610; one processor-direct slot). Its cut-down sibling, the MEMCjr memory controller with the PrimeTime I/O chip, drives the 1993-94 low-cost boards: "Primus" (LC 475), "Aladdin" (Quadra 605) and "Optimus" (LC 575).
