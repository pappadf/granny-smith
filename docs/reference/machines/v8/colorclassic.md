# Macintosh Color Classic

> 🚧 **Placeholder** — this page is planned but not yet written.
<!-- gs-doc-status: stub -->

The LC II architecture in a compact case around the Spice custom IC (1993; also the Performa 250): a built-in 10-inch 512 × 384 colour CRT driven from 256 KB of VRAM, 4 MB soldered with the top 2 MB always mapped at $800000, SWIM2, front-panel buttons, and a Cuda microcontroller [1]. VIA1 PA6/PA4/PA2/PA1 read 0/0/0/1; Gestalt machine type 49 [1] ch. 4. Requires System 7.1 with its System Enabler or later. The family-level facts are in [v8.md](v8.md).
