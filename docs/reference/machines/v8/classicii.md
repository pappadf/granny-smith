# Macintosh Classic II

> 🚧 **Placeholder** — this page is planned but not yet written.
<!-- gs-doc-status: stub -->

The LC architecture in the compact case around the Eagle gate array (1991; also the Performa 200): a built-in 512 × 342 1-bit CRT scanned from main RAM at $9F9A80, 2 MB soldered, the Egret microcontroller, an FPU/ROM connector in place of a PDS [1]. VIA1 PA6/PA4/PA2/PA1 read 0/1/0/1. The family-level facts are in [v8.md](v8.md).
