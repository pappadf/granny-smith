# Workgroup Server 9150

> 🚧 **Placeholder** — this page is planned but not yet written.
<!-- gs-doc-status: stub -->

The Workgroup Server 9150/80 (April 1994) and 9150/120 (April 1995) are the Power Macintosh 8100 board in a server tower, with their own CPU identification (machine-ID register low bits `%100`, Gestalt `$27` / `$39`) and a fourth NuBus slot at slot address `$A` served by the FAT AMIC (Apple, *Workgroup Server 9150* Developer Note, 1995, Table 1 and Figure 1). The family-level facts are in [pdm.md](pdm.md); the machine it derives from is [pm8100.md](pm8100.md).
