# Power Macintosh 7300

> 🚧 **Placeholder** — this page is planned but not yet written.

The Power Macintosh 7300 (February 1997, 166/180/200 MHz PowerPC 604e) is the model Apple's 1997 developer note groups with the 7600, 8600 and 9600, listing the Power Macintosh 7500/100 as its previous model and giving it a new machine ID value, 109 (Apple, *Power Macintosh 7300, 7600, 8600, and 9600 Computers* Developer Note, 1996, Table 1-1 p. 2 and "Machine Identification" p. 17). The family-level facts are in [tnt.md](tnt.md) §6.5; the sibling it is closest to is [pm7600.md](pm7600.md).
