The Power Macintosh 7300 (February 1997, 166/180/200 MHz PowerPC 604e) is the model Apple's 1997 developer note groups with the 7600, 8600 and 9600, listing the Power Macintosh 7500/100 as its previous model and giving it a new machine ID value, 109 (Apple, *Power Macintosh 7300, 7600, 8600, and 9600 Computers* Developer Note, 1996, Table 1-1 p. 2 and "Machine Identification" p. 17). The family-level facts are in [tnt.md](tnt.md) §6.5; the sibling it is closest to is [pm7600.md](pm7600.md).

## 1. Identity

The 7300 is the 7600's board — one Bandit, Hammerhead, Control/Chaos video, MESH and the 53C94 —
without the A/V panel, on a 604e card (168, 180 or 200 MHz on a 48, 45 or 50 MHz bus) [1]
Tables 1-1, 1-2. It ships with the 1997 ROM `$960E4BE9` [2].

**Machine ID 109 comes from the System, not the ROM.** The 1997 ROM carries the 1995 68k
identification routine, and its ProductInfo directory holds the same four records as the 1995
ROM (BoxFlag $3D, $3E, $3F, $66 — the 9500, 7500, 8500 and 7200); no code in it stores $67 to
BoxFlag [2]. A 7300 therefore boots as BoxFlag $3E, the 7500/7600 identity. The System file of
System 7.6 and Mac OS 8.1 installs a startup patch [3] that, when

- BoxFlag is $3E,
- the ROM is the TNT ROM (ROM version word $077D, release byte $28 or $34), and
- the first byte of the $F8000000 identifier is $39 (a Hammerhead),

reads BoxID with a big-endian `AND.L` of $F301A000 — so its masks $00200000 and $00800000 are the
little-endian register's **bits 13 and 15** — and rewrites the identity:

| BoxID (little-endian) | BoxFlag | Gestalt | |
|---|---|---|---|
| bit 13 clear | $68 | 110 | set first, then the bit-15 test below |
| bit 15 clear | $67 | 109 | the 7300 |
| both set | $3E (unchanged) | 68 | the 7500 and 7600 |

each change also re-registering the `'mach'` Gestalt selector [3]. A companion patch turns
BoxFlag $3F (8500) into $3D (9500) when the Hammerhead's +$20 byte has its top three bits clear
[3]. So the 7300's board is distinguished by **BoxID bit 15 strapped low** — the bit the
7500/7600/8500/9500 boards idle high — with bit 13 high (Open Firmware's `AAPL,7500` pick, which
the 7300 shares). Without the patch the machine reports 68.
