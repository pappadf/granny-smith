# Articles

Curated long-form write-ups, publication quality — the public venue for
hardware knowledge that would otherwise live only in interleaved model docs
and research dossiers. Freeform in structure; the content rules R1–R5 of
[../README.md](../README.md) apply in full (R6 deliberately does not: an
article may go deep on one aspect without being the exhaustive record).

The article, *Inside Apple's Casper: the PlainTalk speech recognizer, end
to end* ([plain-talk-recognizer.md](plain-talk-recognizer.md)), publishes
the PlainTalk recognizer write-up as the tree's first long-form page.
