# Power Macintosh 8100/80 (`pm8100`)

The PDM flagship ("Cold Fusion", March 1994): 80 MHz MPC601, 40 MHz bus
(2:1), machine-ID register `$A55A3013`.  Eight fixed-window SIMM banks
(RAM options 8–264 MB); three NuBus slots + PDS slot $E (Phase H); the
second, discrete 53CF96 fast-SCSI bus arrives with Phase G.

See pdm.md for the family model and the boot-ladder status.
