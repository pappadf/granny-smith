# Power Macintosh 7100/66 (`pm7100`)

The mid-range PDM ("Carl Sagan", March 1994): 66 MHz MPC601, 33 MHz bus
(2:1), machine-ID register `$A55A3012`.  Four SIMM banks at the fixed
windows `$01000000 + n×$04000000` (never relocated); three NuBus slots
(`$B`/`$C`/`$D`) behind BART, plus the PDS video slot `$E`, for which no
card is modeled.  RAM options 8–136 MB.

See pdm.md for the family model and the boot-ladder status.
