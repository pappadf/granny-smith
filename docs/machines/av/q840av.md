# Macintosh Quadra 840AV ("Cyclone")

The desktop flagship of the AV family and its first leaf: a 40 MHz 68040 with
the YMCA/PSC/CIVIC chipset, shipped July 1993.
[src/machines/av/q840av.c](../../../src/machines/av/q840av.c) — the family
substrate is [av.md](av.md).

| | |
|---|---|
| Profile id | `q840av` |
| CPU | 68040 @ 40 MHz, integrated MMU + FPU, 32-bit |
| ROM | 2 MB, checksum `$5BF10FD1`, at `$40800000` (shared with the 660AV) |
| YMCA strap nibble | `$F` (Cyclone40) |
| BoxFlag / Gestalt | 72 / 78 |
| RAM | 8 banks × ≤16 MB = 128 MB max; 16 MB default |
| Video | CIVIC + Sebastian, 640×480 Hi-Res |
| NuBus | three slots C/D/E on a MUNI bridge — declared present, no cards in scope |
| Boot software | System 7.1 + **System Enabler 088** (required: its `gbly` gates on machine IDs 72 and 54) |

Everything behaviorally interesting lives in the family substrate; this file
is the profile plus a board descriptor. The deltas against the 660AV are the
strap nibble, the clock, and `muni_present = true`.

## Notes

- **The MUNI is present**, so `MUNI_Control` reads and writes normally and the
  ROM programs it with `$1C` during `JumpIntoROM` (the 40 MHz timing value).
  Contrast the 660AV, where the same access must bus-error.
- **No floppy slot is offered.** The New Age controller is stubbed on the
  documented no-drive path (`ST3 = $FF`), so the profile advertises no drive
  rather than one that never accepts media.
- **NuBus slots are declared but unpopulated** (`nubus_slots = NULL`): AV
  declaration-ROM work is out of scope, and offering sockets the family cannot
  seat would be a lie the config dialog acts on. `machine-capabilities`
  asserts `nubus:false` for exactly this reason.

## Verified

The `av-identity`, `av-ram-sizing` and `av-video` rows of
`tests/integration/suite-av/` cover this machine ROM-only; the
`q840av-71-cd-desktop` row boots it from CD to the Finder desktop once the
test data lands. During bring-up the machine was booted end-to-end from the
dossier's Install-Me-First CD image: POST completes, RAM sizes correctly,
System 7.1 + Enabler 088 load off the CD (BootDrive set, `ApplZone` separated
from `SysZone`), and QuickDraw comes up on CIVIC VRAM at 640×480.
