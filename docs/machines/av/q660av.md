# Macintosh Centris/Quadra 660AV ("Tempest")

The pizza-box sibling of the Quadra 840AV — sold as the Centris 660AV and
renamed "Quadra 660AV" late in life. Same ROM, same chipset, 25 MHz.
[src/machines/av/q660av.c](../../../src/machines/av/q660av.c) — the family
substrate is [av.md](av.md).

| | |
|---|---|
| Profile id | `q660av` |
| CPU | 68040 @ 25 MHz (a full '040, not an LC), integrated MMU + FPU, 32-bit |
| ROM | 2 MB, checksum `$5BF10FD1`, at `$40800000` (shared with the 840AV) |
| YMCA strap nibble | `$B` (Tempest25) |
| BoxFlag / Gestalt | 54 / 60 |
| RAM | same eight-bank YMCA system as the 840AV, 128 MB max |
| Video | CIVIC + Sebastian, 640×480 Hi-Res |
| NuBus | slot E only, on an optional adapter — **absent by default** |
| Boot software | System 7.1 + **System Enabler 088** |

This is the `q950.c` pattern: a profile and a board descriptor, no new
lifecycle code. Three data deltas against the 840AV — strap nibble, clock,
and `muni_present = false`.

## Notes

- **No MUNI by default, and that is load-bearing.** A 660AV without the NuBus
  adapter has no MUNI at all, so reads *and* writes of `MUNI_Control` must
  raise a bus error. That is precisely what makes the ROM's `TestForMUNI`
  clear `MUNIExists`; answering the read instead leaves the flag wrongly set
  and the machine believes it has a NuBus bridge it does not have. The
  `av-identity` integration row exercises this path (reaching the end of the
  row at all means the fault was taken and handled).
- **RAM ceiling.** `RamInfoTempest` is byte-identical to `RamInfoCyclone`, so
  the architectural maximum really is 128 MB; the 660AV's marketing 68 MB
  limit is not encoded in hardware and is not enforced here.
- **Clock chip.** The 660AV uses Clifton (or PUMA on some boards) where the
  840AV uses Endeavor, driven bit-serially through the same address. The ID
  probe answers `$FF`, so this machine takes the Clifton path.
- No floppy slot is offered (the New Age stub reports no drive), and no NuBus
  sockets are declared.

## Verified

Covered by `tests/integration/suite-av/`: `av-identity` asserts the `$B` strap
nibble (strap 2 low, which is what distinguishes a Tempest from a Cyclone) and
exercises the missing-MUNI bus error; `av-ram-sizing` sizes 32 MB on this
model. The `q660av-71-cd-desktop` row boots it to the Finder desktop once the
test data lands.
