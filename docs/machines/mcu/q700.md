# Macintosh Quadra 700

The **Macintosh Quadra 700** ("Spike", 25 MHz 68040, October 1991) is the
desktop member of the MCU/DAFB family and Granny Smith's first 68040
machine. Profile + board wiring:
[src/machines/mcu/q700.c](../../../src/machines/mcu/q700.c); family
substrate: [mcu.md](mcu.md).

Low-speed I/O is direct and IIci-like: VIA1 + VIA2, classic bit-banged
RTC/PRAM on VIA1, the VIA-shifter ADB transceiver, direct SCC and SWIM.
No IOPs, no Egret/Caboose, one SCSI bus. It shares the `420DBFF3` 1 MiB
ROM with the Quadra 900 — the ROM picks the machine from the VIA1 port A
model sense.

## Identity

- **Model sense [R]:** VIA1 PA reads `$C0 | PA0`; the ROM's identify
  table (`$0031C8` in the ROM) matches `PA & $56 == $40`. **PA0 is the
  diagnostic-mode strap and must idle HIGH** — driving it low sends the
  ROM into its serial test manager (an endless SCC poll, no fault).
- ROM row: `Quadra 700/900 ROM`, checksum `0x420DBFF3`
  ([rom.c](../../../src/core/memory/rom.c)); canonical fixture name
  `q700-q900-420dbff3.rom`.

## Device set

| Device | Model | IRQ routing |
|---|---|---|
| CPU | 68040 @ 25 MHz, on-chip MMU/FPU | — |
| Video | DAFB, 2 MiB VRAM ([dafb.md](dafb.md)) | VIA2 PA6 → /SLOTIRQ |
| SCSI | NCR 53C96 + TurboSCSI pseudo-DMA ([scsi_53c96.md](../../core/peripherals/scsi_53c96.md)) | VIA2 CB2 |
| Ethernet | DP83932 SONIC ([sonic.md](../../core/peripherals/sonic.md)), Apple MAC PROM at island `$8000` | VIA2 PA0 → /SLOTIRQ |
| Sound | EASC (ASC-compatible core for now) | VIA2 CB1 |
| Floppy | SWIM, direct | — |
| ADB | VIA1 shift-register transceiver | VIA1 |
| NuBus | two sockets, slots $D and $E (NuBus '90) | PA4/PA5 → /SLOTIRQ |

The 040 PDS is mechanically aligned with slot $E (not modeled as a
constraint). Built-in DAFB video is pseudo-slot 9: its declaration ROM
lives in the system ROM and its apertures are substrate-mapped, so it is
not a card on the bus.

RAM: 4 MB soldered + four SIMM slots; profile options 4/8/20 MB plus the
accepted-in-practice 36/68 MB configurations [R][U].

## Gates (integration tests)

- `q700-boot-chime` — ROM boot, RAM sizing, overlay drop.
- `q700-boot-finder` — Disk Tools floppy → Finder desktop at 640×480,
  pixel-exact.
- `q700-boot-hd` — System 7.1 SCSI HD boot to the desktop (~850M
  instructions), pixel-exact.
- `q700-24ac` / `q700-824gc` — NuBus display cards in slot $D
  (dual-display desktop; the 8•24 GC INIT authentically declines to
  install its accelerator on a 68040).
