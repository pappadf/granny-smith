# Macintosh Quadra 950

The **Macintosh Quadra 950** ("Zydeco", 33 MHz 68040, March 1992) is the
Q900's successor tower — same Eclipse board architecture, faster clock,
DAFB 3, and the AC842a RAMDAC. Profile:
[src/machines/mcu/q950.c](../../../src/machines/mcu/q950.c); it shares
the entire tower device build with the Q900 through
[q900_internal.h](../../../src/machines/mcu/q900_internal.h) (see
[q900.md](q900.md)) — per-machine facts flow through the board
descriptor.

## What differs from the Q900

| Aspect | Q900 | Q950 |
|---|---|---|
| CPU clock | 25 MHz | **33 MHz** (profile `freq`; VIA2 PB5 speed strap reads 1) |
| Model sense | `$D0` (`PA & $56 == $50`) | **`$90`** (`PA & $56 == $10`) |
| DAFB | version 0 | **DAFB 3** (`DAFB_Test` bits 11:9 = 3) |
| RAMDAC | AC842 | **AC842a** — real PCBR1, x555 16 bpp "Thousands" |
| ROM | `420DBFF3` (shared with Q700) | **`3DC27823`**, 1 MiB (`q950-3dc27823.rom`) |

The AC842a/DAFB-3 behaviour (PrimaryInit's PCBR1 presence probe, the
`$C0` x555 direct-color switch, the driver's version-gated
"16 bpp always allowed" path) is documented in [dafb.md](dafb.md).

## Gate (integration test)

`q950-boot-hd` boots the System 7.1 HD image to the desktop
(`BoxFlag == 20`, boxQuadra950), then drives the **real Monitors control
panel** with scripted mouse input — global-warp moves
(`machine.adb.mouse.move X Y global`) plus real ADB clicks through the
SWIM IOP autopoll — switching the display to **Thousands**, and
pixel-matches the 16 bpp desktop. (Plain relative moves are not precise
under ADB acceleration; global-mode clicks don't generate events — the
working recipe is global moves + default clicks.)
