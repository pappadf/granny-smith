# MC68040 MMU

The 040 MMU is a **sibling of, not a patch to**, the 68030 PMMU in
[mmu.c](../../../src/core/memory/mmu.c): implementation in
[src/core/memory/mmu040.c](../../../src/core/memory/mmu040.c) /
[mmu040.h](../../../src/core/memory/mmu040.h). Reference: `MC68040UM`
chapter 3.

## Register file

Reached only via MOVEC (no PMOVE on the 040); owned by the CPU instance
(see [cpu_68040.md](../cpu/cpu_68040.md)):

| Register | MOVEC | Notes |
|---|---|---|
| TC | `$003` | 16 bits used: E (enable), P (page size 4K/8K) |
| ITT0/ITT1 | `$004/$005` | instruction transparent-translation |
| DTT0/DTT1 | `$006/$007` | data transparent-translation |
| MMUSR | `$805` | PTEST result |
| URP / SRP | `$806/$807` | user / supervisor root pointer (512-byte aligned) |

Writes mask to the architecturally writable bits and flush the software
TLB when they can change translations.

## Translation

- **TTR match first**: base/mask compare on A31–A24, S-field
  (user/super/both), write-protect — a hit bypasses the table walk.
- **Fixed three-level walk** from URP/SRP: 7-bit root index, 7-bit
  pointer index, then 6-bit (4K) or 5-bit (8K) page index; indirect
  descriptors followed one level.
- **U/M protocol**: the walker sets Used on each visited descriptor and
  Modified on the page descriptor for a successful write translation,
  with the read-modify-write ordering the manual specifies.
- **PTEST** loads MMUSR with the resident/protection/cache-mode result
  (`MMUSR040_*` bits); **PFLUSH** forms invalidate page/all entries.

## Integration with the bus resolver

`mmu_state_t.m040` links the bus-side MMU to the CPU-owned register file
(`mmu_attach_mmu040`; also re-establishes the backlink and mirrors TC.E
into `enabled` after checkpoint restore). Translation dispatches from
`mmu.c` into the 040 walker; successful walks project pages into the SoA
fast path via `mmu_fill_soa_page`, sharing host resolution, logpoint
suppression, and TLB tracking with the PMMU fill.

## Inspector

`machine.cpu.mmu` (class `mmu040`, bound by `cpu_init`) exposes `tc`,
`itt0/itt1/dtt0/dtt1`, `urp`, `srp`, `mmusr`, and `enabled` — read-only,
for shell probes and debug scripts:

```
> machine.cpu.mmu.tc
0x0000c000
> machine.cpu.mmu.enabled
1
```

## State

The register file checkpoints with the CPU (right after the `cpu_t` blob
in the stream); the bus backlink is a save-time pointer, NULLed on
restore and re-planted by machine init. Unit suite:
`tests/unit/suites/mmu040/` (12 cases: TTR precedence, walk levels, U/M
ordering, PTEST/PFLUSH, page sizes).
