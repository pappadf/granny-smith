# MC68040 CPU model

The 68040 decoder lives in
[src/core/cpu/cpu_68040.c](../../../src/core/cpu/cpu_68040.c). It
instantiates the shared decoder with `CPU_DECODER_IS_68030` semantics as
its base — the 040 user-mode op-set is the 030's — and overrides the
040-specific instructions and system model. Reference:
`MC68040UM` (Motorola user's manual); MOVE16 is specified in `M68000PRM`.

## What the 040 adds / changes

- **MOVE16** — both forms, including `(Ax)+,(Ay)+` (cache-line copy;
  used heavily by System 7.1's BlockMove on the Quadras). Decode +
  disassembly rows are in `cpu_decode.h` / `cpu_disasm.c`.
- **CINV / CPUSH** — cache maintenance, accepted as no-ops with correct
  decode (the emulator has no cache model to invalidate).
- **040 MOVEC set** — the on-chip MMU registers: `$003` TC, `$004–$007`
  ITT0/ITT1/DTT0/DTT1, `$805` MMUSR, `$806` URP, `$807` SRP. The 040
  **has no PMOVE** — MMU state is reached only via MOVEC
  ([mmu040.md](../memory/mmu040.md)).
- **PFLUSH / PTEST** — 040 forms (opcode `F5xx`), dispatched to the
  mmu040 walker.
- **Access-error frame (format `$7`)** — the 040's fault frame; RTE
  handles formats `$0/$1/$2/$3/$7` (frame sizes in `cpu_ops.h`).
- **FSAVE / FRESTORE** — the on-chip FPU's single-longword idle frames
  (`fpu_fsave040` / `fpu_frestore040` in
  [fpu.c](../../../src/core/cpu/fpu.c)); the FP datapath itself is the
  same one the 030+68882 pairing uses (see [fpu.md](fpu.md)).

## Ownership model

Unlike the 030 (whose PMMU is machine-constructed and attached via
`cpu_attach_mmu`), **the 040 owns its MMU on-chip**: `cpu_init` creates
the `mmu040_state_t`, `cpu_delete` frees it, and `cpu_checkpoint` writes
the register file right after the `cpu_t` blob. Machine code links the
register file to the bus-side resolver with `mmu_attach_mmu040`. The
`machine.cpu.mmu` inspector binds in `cpu_init` (class `mmu040` — the
PMMU-shaped class would misread this state).

`cpu_has_fpu` covers the model; hardware reset goes through the 040 reset
path (MMU disabled, TTRs cleared).

## Tests

`tests/unit/suites/cpu040/` (20 cases: MOVE16 forms, MOVEC set, frame
formats, FSAVE/FRESTORE) and `tests/unit/suites/mmu040/` (the walker;
see [mmu040.md](../memory/mmu040.md)). The 68000/68030 suites and the
single-step tests are untouched by the 040's presence.
